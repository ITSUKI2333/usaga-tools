# 已知回归和构筑入口迁移

本目录保留了修复源码，不能把历史个别界面的成功测试当作新工具全局实机验收。

## 必须保留的工程约束

1. UI 度量与字形实际渲染要一致。保留原逻辑光标、窗口返回和等待语义；不能仅放大字形或把分页输入当作自动换行补救。
2. EE 支持的浮点转整数路径使用 CVT.W.S；不能混入未支持的 TRUNC.W.S 导致菜单翻页/交互异常。
3. 脚本资源扩大后，关联图像、直接流式语音、音乐/STR 的指针也要按类型处理；不能只重定位文字或对所有 GetADR 调用统一加差值。关联相对指针已指向新基址时不得二次平移。
4. 原生窗口池有 9 项，步长 0x1804。未绑定索引 FF 可能使窗口清零写入扩展字体 RAM；47 个计算窗口指针位置的隔离修复与独立完整窗口大小的 sink 必须配套。不能据此改造原生窗口数量。
5. 扩展第二页、注入代码、sink、堆起点及音频区不得重叠。当前研究模块的地址约束针对日版已分析 ELF 布局，不是运行时动态分配器。
6. 字库页只是像素资源；编码、字形坐标、宽度、分页/缓存失效、资源加载及存档读入路径要联合核验。存储卡读档后恰好恢复显示不代表字体初始化正确。
7. 原版短假名可能是单字节；中文汉字通常占两个或扩展后的四个字节。字数相同不代表长度相同。必须以实际编码字节、控制码和可证实入口规划写回，不能按字符数判断容量。
8. 文本/图像常有重复资源与运行时所选副本。最终 ISO 中某处“已写入”不证明画面使用它；需要记录当前加载表、目标资源、包内子图/文本引用，并从最终副本回读。MAPC 与 GRA 不能混用封包格式。
9. 新 ISO 与旧即时存档可能保留不同代码、资源和缓存；存储卡读档和即时存档是不同路径。验证新补丁必须记录启动/读档方式、ISO 身份和现场状态，不能用“旧存档”解释一切。
10. 残留日文不能只按假名筛查；纯汉字、图片字、未走到的脚本和运行时别名均需独立覆盖。保留原文槽位的重定位资源可能静态看似未改，核验时应跟随当前加载表和对应别名入口。

相关模块：`usaga_two_page_font`、`usaga_ui_spacing_runtime`、`usaga_ui_physical_wrap`、`usaga_window_isolation`、`usaga_cn_extended_codec`。

## 尚未成为独立通用命令的全量构筑链

历史 `prepare_usaga_full_cn_ui.py` 和 materializer 使用先前原始文本记录、多个准备产物、UI 边界审计、旧版条目判断、字体行宽与已核验布局计划。只把 ROOT 换成命令行参数会掩盖这些依赖。

初次审批稿保留过 `research/pipeline/*.py.txt` 阅读快照；最终审批稿已将这批私人依赖入口移出公开范围。核心算法仍保留在实验模块。**当前阶段没有声称历史完整构筑已经移植完成。**

下一阶段迁移应采用明确输入产物契约：

| 阶段 | 输入契约 | 必须输出/检查 |
|---|---|---|
| Extract | 原版 ISO/ELF、人工字表、版本 profile | 逐地址原始记录、表引用、未解析项、源散列 |
| Translate | CSV、控制码和地址不变 | 冲突/遗漏/完全相同编码的重复项 |
| Layout | 原始指令图、字符串用途、字宽 | 指令边界证据、窗口/列/数值坐标计划 |
| Font | 字表、字体、固定基线参数 | 所有页、宽度、缺字检查、原生容器封包 |
| Prepare | 上述产物及明确版本 | 资源重定位、名称表压缩、ELF 字库/UI/媒体钩子 |
| Verify | 准备副本、原版源 | 字体/堆/窗口/媒体区间、全部控制码、typed ADR、可回读文本 |
| Materialize | 核验通过的准备目录 | 新 ISO、所有差异范围和完整散列；原件不变 |
| Runtime QA | 冷启动的新 ISO | title、选人、设置、商店、装备高亮、技能板、战斗、冒险、语音和读档 |

不把旧构筑路径、私人内存快照或临时报告打包成公开依赖；不把历史“已通过”写死绕过新检查。稳定 CLI 的有限写回与实验重定位模块明确分开。

外部验收版的别名协议及测试函数不属于本次拟授权源码；当前项目后续补写曾依赖该验收包，但公开工具未引入其代码或验证资源。迁移外部实现需先明确作者、授权、输入协议和独立测试，不能把本机可用与可公开复用混为一谈。
