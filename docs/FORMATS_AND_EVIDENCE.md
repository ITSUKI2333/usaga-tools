# 格式与分类依据

## 支持版本与输入身份

仅支持日版 SLPS-25199：原 ELF SHA-256 `3f66b74b090a90fd3cb7573b9c7c4ef9ed1299fe3ee36c1f6d84cccd80ac2760`；原 ISO SHA-256 `62882bb08356dc3457f65e6bbee08e712b5be4a16faf803636226d3dcac87e54`，大小 3685679104。提取前检查 ELF 散列、ISO 大小及 ISO 内 0xFA800 处完整 ELF；写回前额外验证整个 ISO 散列。身份检查不支持跳过。

## 原版游戏编码

字形编号与 Unicode 不是同一件事。原始脚本大部分并非标准 Shift-JIS。

- 原版单字节 `30..FF` 对应字形 0..207。
- 其他正常字形编码为 `0x2830 + glyph_index` 两字节大端值，范围限原版 1764 字；低字节可为 00，不能用普通 C 字符串函数任意截断。
- `0x2700..0x282F` 是特殊码区域，保留原始十六进制 token，不据此猜 Unicode。
- `<0x27` 进入脚本/控制流处理。只有已验证上下文可把某一字节当作结束符。
- 扩展四字节编码与字体页需要配套 ELF 钩子；稳定 CLI 不自动用它写入游戏。

外部人工字表是必需输入。游戏原始字体图集的坐标只能确定编号，不能自行证明汉字身份；本源码没有 OCR、图像相似度或网络日文文本回填。

## 资源与名称表

ELF `mes_sector_table` VA 0x81B420 是 513 项 uint32 扇区表，每个 MES 脚本使用 [2*i,2*i+1] 两项界定；扇区 2048 字节。脚本后相邻资源可能是图像/音频，不能当纯文字池一并搬动。

`tono_sector_table` VA 0x81B3C0 第 5 号共用资源为 TONO5。当前日版 ISO 区域为 0x4AD19000–0x4AD40800。

## 说明表

TONO5+0x1A560 与 MES17+0x10 都有 645 项说明脚本指针，后者还有装备能力、术效果和术目标说明表；TONO5 另有重要道具/术具说明表。准确参数在 `cli.py/HELP_TABLES`。

按指针的下一个唯一目标设置单条脚本边界，在该范围定位 `16 10` 显示片段。颜色/属性变化可能将一句说明分成多段。导出真实片段和引用，不伪造一个跨控制指令的连续文字字节区。

说明表有别名及重复等级项。尚未把说明表索引完整证明为技能 ID/等级，所以不采用“索引除以 5 就能对应名称”的推断。

## 脚本遍历与图片

复用既有 ELF 指令长度推导和派发表别名、图遍历、显示指令锚点及连续文字池规则。未解释操作码明确导出失败位置；自然语言候选只是待核验，不作为证实文本。ISO 顺序不等于剧情播放顺序。

最终复核修正 `16 14` 为 7 字节，其 mode 3 的本地目标从 `+3` 读取；其他模式不推测静态目标。`16 06/07` 为 8 字节；`16 05` 的 mode 3 为 3 字节、其余已知 mode 0..4 为 7 字节。依据为原版派发后 seqadr 已越过两字节操作码，相关 handler 的读取位置和 continuation；合成测试包含与旧偏移不同的目标。新结果必须重新跑提取和差异检查，不能沿用旧条数作为验收门槛。

TIM2 扫描覆盖整个 ISO，分块读取并保留跨块 3 字节尾部，验证图片头、大小及边界；仅结构通过才可导出，有 64 MiB 单项上限。结构有效不等于已验证原始独立文件边界。PNG 解码/原生 GRA 导出目前针对已确认的索引图+调色板结构；8 位 CSM1 调色板交换位 3/4，PS2 alpha ×2 后截断。线性存储是特定上传结构的解释，不擅自对未知纹理反交换。

新增加的 MAPC 菜单包和 LAY 分页角色资源有不同格式及验证范围，见 [LAY_AND_MAPC](LAY_AND_MAPC.md)。
