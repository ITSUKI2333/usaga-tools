# 私有构筑链的公开边界

初次审批稿附带了九份历史 `.py.txt` 快照。最终审批稿将其移出公开目录：它们仍引用具体构筑批次、私人报告、译文样例和运行时内存，不能靠改 ROOT 即独立运行。原始快照仍保存在项目持有人本机的上次审批包中。

可复用的字体、UI、窗口隔离、别名和溢出恢复实现保留在 `usaga_tools/experimental/`，并已同步本轮之前的当前项目实现。完整构筑入口需要按 [迁移契约](../docs/MIGRATION_AND_REGRESSIONS.md) 重新整理输入与核验产物。

外部验收包的源码、游戏内容和复用测试函数没有复制进本公开目录；不能把它的成功验收记作公开工具的功能或授权。
